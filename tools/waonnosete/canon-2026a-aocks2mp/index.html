ご購入ありがとうございます。このページから、いつでも最新版をひらけます。ブックマークをおすすめします。

1まずは開いてみる（30秒）

下のボタンで、ブラウザでそのまま使えます。「おてほん」→「▶ きく」で、チェロとチェンバロのばん奏にのって、リコーダーの音でせんりつが鳴ります。そのまま「🎼 カノンできく」を押すと、3グループのカノンになります。

▶ ブラウザで開く ⬇ ファイルをダウンロード

マイクは使いません。ダウンロードしたファイルは、ダブルクリックで開いてもそのまま動きます。

2授業での使い方

🎵 おすすめの流れ：教科書の「カノン」をリコーダーで吹く（カノンであそぼうで「なぜ4小節ずつ？」まで） → このツールで、同じ和音の進み方にのせて自分のせんりつをつくる → 「🎼 カノンできく」で追いかけっこにして聴く → 「🎵 ゆびミエ」に送って、自分のカノンをリコーダーで吹く
  • 和音は1小節ずつ C→G→Am→Em→F→C→F→G とかわり、8小節でひとまわりします（パッヘルベルのカノンの和音の順番。ハ長調）。小節の上に和音が出て、和音の音のマスには薄い色がつきます
  • 左の「ながさ」（♪・♩・2はく・やすみ）をえらんで、マスをタップすると音が入ります。同じマスをもう一度タップで消えます。ちがう高さをタップすると高さだけ変わります
  • ルール（✔・？）：小節のはじめの音は、その小節の和音の音のどれかから／最後の音は「ド」（そのあと「おわりの和音」が鳴ります）。守れていない小節には ？ とヒントが出ます（止めはしません。⚙「アドバイス表示」で消せます）
  • 🎼 カノンできく：3グループが8小節（和音がひとまわりする長さ）ずつずれて入ります（まん中→左→右の順に、音の位置もずれます）。画面では3本の線が別々の色で進み、鳴っている音がグループの色で光ります。8小節のままだと、じゅんばんに吹くだけで重なりません——ここで「だから16小節」が分かります
  • 8・12・16小節：右上でえらぶ →「1〜8小節をコピー」→ 9小節めからを少し変える。はんぷく・へんか（A B C D E F G H A B′ C D′ …）のラベルが自動でつきます
  • リズムカード：カードをえらんで小節の「▼」を押すと、そのリズムが1タップで入ります。「＋ じぶんのリズム」で先生のカードを追加できます
  • はんぷく：小節の和音チップをタップ →「▼ ここにうつす」で、その小節をほかの小節にうつせます
  • 📝 かし：音をタップしてことばを入力。がくふで五線譜（和音名つき）にして画像保存できます
  • 🎤 うたう・🎵 ふく：⚙でうたミエ／ゆびミエ フル版のURLを入れておくと、作ったせんりつを曲入りリンクにして送れます。ゆびミエなら、自分のカノンをそのままリコーダーで練習できます
  • ⚙ 先生用：ばん奏（カノンのばん奏／1拍目と3拍目／毎拍）、楽器、和音ごとに使える音（5つの和音それぞれ）、使える音符、カード、テンポ、メトロノーム、アドバイス表示、パスワード／⚙を隠す
  • 🔗 リンク：作ったせんりつが入ったURLをコピー。先生が押すと先生の設定つきのリンクになるので、それを配れば子どもの端末でも同じ縛りで使えます。子どもが押せば作品の提出用になります
  • 📄 MusicXML：作ったせんりつを楽譜ファイル（.musicxml）で保存。和音記号（C・G・Am…）と、ピアノ（和音・全音符で4拍のばす）・チェロのばん奏パートつき。「カノンの形」を選ぶと、グループ1・2・3が8小節ずつずれて入る楽譜になります。Flat for Education の「インポート」で開けば、そのまま清書・印刷・パート譜にできます
  • 💾 ほぞん／📂 ひらく：なまえをつけてこの端末に保存。📷 かきのこす：グリッドとリズムを画像で保存

「カノンであそぼう」の「じぶんのカノン」は、♩𝅗𝅥𝅝だけで手ばやく試す入口です。こちらは♪・やすみ・リズムカード・かし・五線・先生の設定まで入った、音楽づくりの授業用です。

3子どもの端末に配る

いちばん簡単なのは、このページの「ブラウザで開く」のURLをロイロノート・Classroomに貼る方法です。子どもはタップするだけで、登録もインストールもいりません。ファイル（waonnosete-canon.html）を配布しても動きます。⚙で設定してから「🔗 リンク」を先生が押せば、使える音やテンポも引きつがれます。

📋 ライセンスの範囲：ご購入された先生の授業・学級でのご利用に限ります。他の先生への共有や、SNS等での再配布はご遠慮ください。校内全体でのご利用はスクールライセンスをご検討ください。

4うまくいかないとき

音が出ない端末の消音スイッチ・音量を確認 → 画面をどこかタップしてから「▶ きく」→ それでも出なければページを再読み込み
カノンにしても重ならない8小節のままです。右上で「12小節」か「16小節」にしてください（8小節だと、3グループがじゅんばんに吹くだけになります）
マスをタップしても入らないグレーのしま模様のマスは、⚙「和音ごとに使える音」で外した音です。プリセット「すべて」で戻せます
ばん奏をピアノにしたい⚙「和音のならし方」を「1拍目と3拍目にジャン」にして、「和音の楽器」でピアノなどを選びます
その他公式LINE、または info@ktteacher.net までご連絡ください。画面の写真を送っていただければ、その場面に合わせてご案内します
