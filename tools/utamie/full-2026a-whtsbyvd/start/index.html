1まずは開いてみる(30秒)

下のボタンで、ブラウザでそのまま使えます。「📚 きょうざいきょく」から曲をえらんで、「🎤 歌ってみる」でおためしください。

▶ ブラウザでフル版を開く ⬇ ファイルをダウンロード

ダウンロードしたファイルは、ダブルクリックでオフラインでも動きます。※圧縮形式(.mxl)の楽譜読み込みだけはオンライン時のみ。ふつうの .xml / .musicxml はオフラインでも読み込めます。
※端末によっては、ダウンロードしたファイルを直接開くとマイクが使えないことがあります。その場合は上の「ブラウザでフル版を開く」をお使いください。

25つのつかいかた

  • 🎤 歌ってみる: 歌った声の高さが、その場で線になって流れます。青いブロック(お手本)にオレンジの線が重なれば合っています。「もっと高く」と言うかわりに、子どもが自分で合わせにいけます
  • ▶ お手本をきく: 曲を鳴らして音を確かめます。「お手本をくりかえす」でループできます
  • 🦜 まねっこ: お手本のフレーズ → 自分が歌う、を交互に。音取りの入口に
  • 🌬 ロングトーン: 1つの音をのばして、まっすぐ保てているかを見ます
  • 🐤 こえあそび: 曲なしで声を出して線を動かします。マイクチェックはまずこれで
🎵 合唱の音取りで効くところ
・れんしゅう区間: 「小節◯〜◯」だけをくりかえせます。難所だけ集中的に
・移調(−/＋): 変声期に合わせて下げられます。原調にこだわらず声を出せます
・テンポ: 50〜130%。ゆっくりから入って戻していけます
・判定のきびしさ: 「ふつう／やさしい／いちばんやさしい」。最初は「やさしい」のままで大丈夫です

💡 お手本を流しながら正確に判定したいときは、イヤホン・ヘッドホンでお手本を聴くのがいちばん確実です。
🔊「じぶんの歌をきく」で録音を再生、📷「けっかカードをほぞん」で結果を画像に残せます。

3自分の教材曲を入れる

  1. Flat for Education などから MusicXML形式(.xml / .musicxml / .mxl)で書き出します
  2. 「📂 楽譜ファイルをひらく」で読み込みます
  3. 「📚 きょうざいきょく」→「📌 追加」で、この端末に登録できます

登録した曲は ✏️ ボタンで名前を変えられます。「ソプラノ」「アルト」「パート1」など、子どもがわかる名前に直しておくと親切です。

楽譜に曲名が入っていない場合は、ファイル名が自動で曲名になります。

配布用ファイルへの焼き込み:「組み込み用コード」をコピーし、テキストエディタでファイル内の PRESETS 配列に貼り付けて保存すると、開いた瞬間から曲が入った状態のファイルを作れます。

⚠️ 教科書掲載曲など著作権保護曲を焼き込んだファイルは、ご自身の授業・学級の範囲内でのみお使いください。学校外への配布はパブリックドメイン曲のみでお願いします。

4🔗 曲を入れたまま配る(いちばんかんたん)

ファイルを配らなくても、URLを貼るだけで、その曲が入った状態で子どもの画面に出せます。

  1. ツールで曲を出す(内蔵曲をえらぶ／📂で楽譜をひらく)
  2. 「📚 きょうざいきょく」→「📌 追加」で曲リストに入れる
  3. その曲の 🔗 はいふリンク を押す → URLがコピーされます

あとは Google Classroom・ロイロノート・Teams・学級のページに貼るだけ。子どもはタップすれば、もうその曲が入った画面が開きます。

📌 ファイルの受け渡しが要りません。「開けません」の対応も要りません。家でも同じリンクで練習できます。
※URLがとても長いのは、曲のデータがURLの中に入っているためです。そのまま貼って大丈夫です。曲の中身がサーバーに送られることはありません。

5生徒の端末に配る

上の 🔗 はいふリンク がいちばん手軽ですが、ファイルそのものを配ることもできます。Google Classroom・Teams・ロイロノートなどで配布でき、生徒はダウンロードして開くだけ。登録・インストールは不要です。

🔒 マイクの音はすべて端末の中だけで処理されます。歌声や録音データがサーバーへ送信されることはありません。

📋 ライセンスの範囲: ご購入された先生の授業・学級でのご利用に限ります。他の先生への共有や、SNS等での再配布はご遠慮ください。校内全体でのご利用はスクールライセンスをご検討ください。
※このURLは学期ごとに変更します。変更のご案内は公式LINEで必ずお送りします。

6うまくいかないとき

声をひろわない①まず「🐤 こえあそび」でマイクチェック ②それでもダメなら「マイク」をクリア(処理なし)に切り替え ③静かな場所で1人ずつ
線がゆれる・ぶれる端末から30cmほど離れて、まっすぐ声を出してみてください。「判定」をいちばんやさしいにすると拾いやすくなります
オクターブちがいで×になる「オクターブちがいOK」にチェックが入っているか確認してください(既定はオン)。男子と女子が同じ曲を歌うときに効きます
お手本の音を拾ってしまうイヤホン・ヘッドホンでお手本を聴くのがいちばん確実です。または「お手本も鳴らす」のチェックを外してください
楽譜が読み込めないFlatの「エクスポート → MusicXML」で書き出してください。.mxl(圧縮形式)はオンライン時のみ読み込めます
曲名が変な名前になる楽譜に曲名が入っていないときに起こります。「📚 きょうざいきょく」の ✏️ で直せます
音が出ない端末の消音スイッチ・音量を確認 → ページを再読み込み → ボタンを押してから操作
その他公式LINE、または ktteacher2023@gmail.com までご連絡ください。画面の写真を送っていただければ、その場面に合わせてご案内します
